✅ Action Menu:
  • "Sample Card" button appears below "Start Sampling"
  • Only active when status = "sampling" (Stage 4)

  • Integrated in both main dashboard and fallback dashboard
  • Access control: Level 1 sees own records, Level 3 sees all
🎨 Visual Design:
