🎯 PDF Generation Workflow:

Complete Process:
  1. User clicks "Sample Card" in action dropdown
  2. Confirmation dialog: "Are you sure you want to complete the sample card?"
  3. User confirms → PDF automatically generates and downloads
  4. Status updates to "sample card"
  5. Stage 4 (Start Sampling) becomes disabled

🔧 Technical Implementation:

Backend (server.py):

PDF Generation Function:
• generate_sample_card_pdf(quotation)
• Uses ReportLab library for A4 PDF creation
• Professional table layout with borders and styling
• Error handling for missing ReportLab package

Download Endpoint:
• GET /quotation/sample-card/<quotation_id>
• Generates PDF buffer and returns as download
• Filename: Sample_Card_[ItemCode]_[DateTime].pdf

Frontend (view_quotations_simple.html):

Action Handler:
• generateSampleCardPDF(id) - triggers download
• updateQuotationStatus(id, 'sample-card') - updates status
• Creates temporary <a> element for download trigger
• Automatic file download to user's device

📊 Data Mapping:

Quotation Fields → PDF Content:
  • customer_name → Customer field
  • key_person_name → Contact field
  • customer_item_code → Item Code field
  • width × length → Dimensions field
  • quality → Quality field
  • flat_or_raised → Surface field
  • direct_or_reverse → Print field
  • num_colors → Colors count
  • color_names (JSON) → Color Names list
  • thickness → Thickness field
  • attachments.length → Additional Files count
  • created_at → Created date
  • last_updated → Last Updated date
  • revision_count → Revision number
