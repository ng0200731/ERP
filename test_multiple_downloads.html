📥 Sample Card Multiple Downloads - v1.4.10

✅ Feature Implemented: Sample Card button remains ACTIVE after first download, allowing users to download the PDF multiple times as needed.

🔄 Updated Behavior:

Previous Behavior (v1.4.09):
  • Click "Sample Card" → PDF downloads
  • Status updates to "sample card"
  • Sample Card button becomes DISABLED
  • Users cannot download again
New Behavior (v1.4.10):
  • Click "Sample Card" → PDF downloads
  • Status remains "sample card" (no change)
  • Sample Card button stays ACTIVE
  • Users can download multiple times

🎯 Button State Logic:

Status: "sampling" (Stage 4)

• First time clicking Sample Card
• Generates PDF and updates status to "sample card"

Status: "sample card" (Stage 5)

• Sample Card button remains ACTIVE
• Users can download PDF multiple times
• No status change on subsequent downloads

🔧 Technical Changes:

1. Button State Logic Updated:

Before:
if (status.includes('sample card')) {
  states.sampleCard = { disabled: true }; // DISABLED
}

After:
if (status.includes('sample card')) {
  states.sampleCard = { disabled: false }; // ACTIVE
}

2. Action Handler Modified:

Before:
generateSampleCardPDF(id);
updateQuotationStatus(id, action); // Updates status

After:
generateSampleCardPDF(id);
// No status update - allows multiple downloads

3. Confirmation Message Updated:

Before:
"Are you sure you want to complete the sample card?"

After:
"Download Sample Card PDF? You can download this multiple times as needed."
