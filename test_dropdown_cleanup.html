🔧 Dropdown Cleanup Test v1.4.04

Test Purpose: Verify that action dropdowns close properly when navigating or clicking buttons.

📋 Test Instructions:

  1. Go to Quotation Records page
  2. Click an Action button to open the dropdown menu
  3. Try the following actions and verify the dropdown closes:
    • ✅ Click outside the dropdown
    • ✅ Click on any navigation button (Customer, Create, etc.)
    • ✅ Click "Return to Records" from a quotation view
    • ✅ Click "Edit" button in quotation view
    • ✅ Scroll the page
    • ✅ Switch browser tabs (blur event)
    • ✅ Resize the window

🎯 Expected Behavior:

✅ PASS: Dropdown should close immediately in all scenarios above
❌ FAIL: Dropdown remains visible after navigation or actions

🔧 Technical Implementation:

  • Global cleanup function: window.closeAllDropdowns()
  • Quotation dropdown cleanup: window.closeQuotationDropdown()
  • Event listeners: click, scroll, blur, resize, visibilitychange
  • Navigation hooks: All navigation buttons call cleanup
  • DOM observer: Watches for content changes in right-frame
